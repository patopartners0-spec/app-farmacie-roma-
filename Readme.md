Voglio costruire una web app per informatori scientifici del farmaco (ISF) di Roma. Prima fase: una mappa interattiva di Roma con tutte le farmacie, suddivisa nei 19 ex municipi in vigore fino al 2013 (prima della riforma a 15).

Dati: elenco farmacie dagli open data del Ministero della Salute, filtrando solo il Comune di Roma e solo le farmacie attive (data fine validità vuota). Confini degli ex municipi ricostruiti unendo le 155 zone urbanistiche storiche del 1977, non la nuova suddivisione del 2026.

Funzioni: filtro per ex municipio, conteggio farmacie per municipio, scheda farmacia con indirizzo, ricerca per nome. Deve funzionare bene da smartphone.

Vincoli: app statica, senza server né database, pubblicabile gratis su GitHub Pages. Interfaccia in italiano.

Prima di scrivere codice:
1. dimmi quali dati riesci davvero a scaricare; se un download è bloccato dimmelo e ti carico io il file;
2. mostrami la tabella zona urbanistica → ex municipio e segnalami i casi dubbi;
3. dimmi se mancano coordinate per alcune farmacie;
4. proponimi il piano.
Aspetta la mia conferma prima di procedere.
